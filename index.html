How to add your own photos and videos

Every placeholder looks like this. The striped box and label disappear as soon as you add a file path to src:

<figure class="media" style="--ar:4/5" data-label="HERO IMAGE 1200 × 1500 · 4:5">
  <img src="" alt="Describe the photo">
</figure>
  1. Put your files in the media/ folder, for example media/hero.jpg or media/tour.mp4.
  2. Open the design's HTML file and search for MEDIA ZONE or src="".
  3. Image: set src="../media/hero.jpg" and write a short alt description.
  4. Video: set src="../media/tour.mp4" and poster="../media/tour-poster.jpg". Background videos should stay muted autoplay loop playsinline.
  5. Swap an image for a video, or the other way round, by replacing the <img> tag inside the <figure> with a <video> tag. The frame keeps its shape.
  6. To change a frame's shape, edit --ar (for example --ar:1/1). Photos are cropped to fit automatically (object-fit:cover).
<!-- after -->
<figure class="media" style="--ar:16/9" data-label="CLINIC TOUR VIDEO">
  <video src="../media/tour.mp4" poster="../media/tour.jpg" controls playsinline></video>
</figure>

Tips: export JPG/WebP images at the listed size, under about 300 KB each. Keep MP4 (H.264) videos under 10 MB, and keep hero loops under 15 seconds. CMS-ready: each <figure class="media"> is a self-contained slot. In WordPress, Webflow or Squarespace, map each one to an image or video field that has the same aspect ratio.
